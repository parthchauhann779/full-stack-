# Lab Sheet 6 — REST API

## Start the API
1. Open terminal in `server`.
2. Run `npm install`.
3. Copy `.env.example` to `.env` and keep the API key value consistent with the demo key in the React app.
4. Run `npm run dev`.

## Plain JS client
Open `client/index.html` using VS Code Live Server while the API is running.

## React client
In `client-react`, run `npm install`, copy `.env.example` to `.env.local`, then `npm run dev`.
The demo API key is intentionally for classroom use only; do not use a client-side secret in a production app.
