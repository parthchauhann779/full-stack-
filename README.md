## Run overview
- Lab Sheet 1: open `LabSheet 1/index.html` in a browser.
- Lab Sheet 2: open `LabSheet 2/index.html` in a browser or Live Server.
- Lab Sheet 3: open a terminal in `LabSheet 3`, run `npm install`, then `npm run dev`.
- Lab Sheet 4: run each task with `node filename.js`; run `npm install` for `nanoid`.
- Lab Sheet 6: follow `LabSheet 6/README.md`.
- Lab Sheet 7: open `LabSheet 7/LabSheet7.sql` in MySQL Workbench and execute statements sequentially. Run rollback/commit demonstrations separately.

**Before submission:** run the programs in your own environment and capture screenshots of their outputs if your teacher requires evidence. `.env` secrets are not included; use `.env.example` to create a local `.env`.
